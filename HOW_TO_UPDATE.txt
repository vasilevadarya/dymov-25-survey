КАК ОБНОВЛЯТЬ САЙТ ПОСЛЕ ПЕРВОГО ЗАПУСКА
=========================================

1. Не создавайте новое приложение и новую PostgreSQL-базу.
2. Изменения в коде/опросах вносите в этот же проект.
3. Перед публикацией обязательно выполните:
   npm test
4. Если проверка пишет OK — загрузите изменения в тот же Git-репозиторий.
5. При включённом автодеплое Timeweb обновит приложение автоматически; иначе нажмите «Запустить деплой» в App Platform.
6. PostgreSQL, Session ID и уже собранные ответы при обычном обновлении приложения сохраняются.

ТЕКУЩИЙ КОНТРАКТ МАРШРУТИЗАЦИИ
------------------------------
- На первом экране только Русский / Қазақша.
- Русский + Офис → единственный офисный опрос 100 вопросов.
- Русский + Производство → бизнес-версия автоматически.
- Қазақша → упрощённый производственный опрос на казахском автоматически.
- Никакого выбора «бизнес / упрощённый» сотруднику не показывается.
