# Дымов 25 — опрос сотрудников (Timeweb Cloud)

Финальная Timeweb-версия.

## Маршруты

### Основной сайт `/`
Первый экран: только два языка.

- **Русский** → после вводного экрана сотрудник выбирает `Офис` или `Производство` и стаж.
  - Офис, стаж 3 месяца и более → **единственный офисный опрос «100 шагов на пути к успеху»**.
  - Производство, стаж 3 месяца и более → **автоматически бизнес-версия производства**. Никакого выбора между бизнес/упрощённой версией нет.
  - Стаж менее 3 месяцев → отдельный опрос адаптации нового сотрудника, как и раньше.
- **Қазақша** → после вводного экрана сотрудник **сразу попадает в упрощённый производственный опрос на казахском**. Подразделение, стаж и версия опроса не спрашиваются.

### Отдельные маршруты
- `/commercial` — опрос сотрудников продаж и маркетинга.
- `/admin` — защищённая админка и выгрузки.
- `/live` — проверка работающего процесса приложения без зависимости от PostgreSQL.
- `/health` — проверка приложения и PostgreSQL.

## Контрольные количества
- Офис: 97 основных + 3 финальных вопроса доверия = **100**.
- Производство RU: 85 вопросов из финального Excel 28.08 + 1 ранее согласованный вопрос о городе/площадке + 3 финальных вопроса доверия.
- Производство KZ: 76 вопросов упрощённой финальной версии 28.08, переведённых на казахский + 1 вопрос о городе/площадке + 3 финальных вопроса доверия.

## Источники производства
В `reference/` лежат оба финальных Excel пользователя от 28.08 и JSON-манифесты для автоматической проверки сборки.

## Технологии
- Node.js 22
- Express
- PostgreSQL
- Docker
- Timeweb Cloud App Platform

При старте приложение само создаёт таблицы PostgreSQL (`CREATE TABLE IF NOT EXISTS`).
Подтверждённый ответ не перезаписывается: на уровне БД действует `UNIQUE(session_id, question_id)`.
