ДЫМОВ 25 — ПЕРВЫЙ ЗАПУСК НА TIMEWEB CLOUD
===========================================

ФИНАЛЬНАЯ ЛОГИКА
----------------
Русский → Офис → один офисный опрос «100 шагов на пути к успеху».
Русский → Производство → бизнес-версия автоматически.
Қазақша → упрощённый производственный опрос на казахском автоматически.
Продажи/маркетинг остаются на отдельной ссылке /commercial.

ШАГ 1. POSTGRESQL
-----------------
Timeweb Cloud → «Базы данных» → «Создать» → PostgreSQL.
Рекомендуемые параметры первого запуска:
- PostgreSQL 17;
- регион Москва;
- минимальная конфигурация;
- без репликации на тестовом этапе;
- публичный IPv4 для простого первого запуска;
- TLS включён;
- бэкапы включены.

После создания сохраните Host / Port / Database / User / Password.
Пароль не отправляйте в чат и не храните в Git.

ШАГ 2. GIT-РЕПОЗИТОРИЙ
----------------------
Timeweb App Platform разворачивает Dockerfile из Git-репозитория.
Подойдут GitHub, GitLab, Bitbucket или Git URL.
Создайте приватный репозиторий и загрузите ВСЁ содержимое этой папки.
Dockerfile должен находиться в корне репозитория.

ШАГ 3. APP PLATFORM
-------------------
Timeweb Cloud → App Platform → «Создать».
Тип: Dockerfile.
Подключите репозиторий, выберите ветку main/master и регион Москва.
Путь до проекта оставьте пустым, если Dockerfile в корне.
Путь проверки состояния: /health

ШАГ 4. ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ
---------------------------
DB_HOST=<host из PostgreSQL>
DB_PORT=5432
DB_NAME=default_db
DB_USER=<user из PostgreSQL>
DB_PASSWORD=<пароль PostgreSQL>
DATABASE_SSL=true
DATABASE_SSL_REJECT_UNAUTHORIZED=false
ADMIN_USER=admin
ADMIN_PASSWORD=<длинный уникальный пароль для админки>

ШАГ 5. ДЕПЛОЙ
-------------
Запустите деплой.
Docker-сборка автоматически проверит:
- один офисный опрос;
- офис = ровно 100 вопросов с финальным доверием;
- языки = Русский / Қазақша;
- RU Производство = финальная бизнес-версия 28.08;
- KZ = финальная упрощённая версия 28.08 с тем же порядком/типами/логикой;
- отсутствие выбора версии производства.

ШАГ 6. ПРОВЕРКА
---------------
Сначала откройте:
https://<технический-домен>/health

Ожидается:
{"ok":true,"service":"dymov-25-survey","database":"ok"}

Затем:
Основной опрос: https://<технический-домен>/
Продажи и маркетинг: https://<технический-домен>/commercial
Админка: https://<технический-домен>/admin
