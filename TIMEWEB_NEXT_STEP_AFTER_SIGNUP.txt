ДЫМОВ 25 — ЧТО ДЕЛАТЬ ПОСЛЕ РЕГИСТРАЦИИ В TIMEWEB CLOUD
=======================================================

СЕЙЧАС НУЖЕН ТОЛЬКО POSTGRESQL. APP PLATFORM ПОКА НЕ СОЗДАВАТЬ.

1. В Timeweb Cloud слева откройте «Базы данных».
2. Нажмите «Создать» / «Добавить».
3. Выберите PostgreSQL.
4. Версия: PostgreSQL 17 (можно 18, если панель предлагает её по умолчанию).
5. Регион: Москва.
6. Конфигурация: минимальная Premium NVMe 1 CPU / 1 ГБ RAM / 8 ГБ NVMe для первого запуска достаточна.
7. Репликация: не включать на тестовом этапе.
8. Сеть: для самого простого первого запуска включите публичный IPv4. Соединение с PostgreSQL будет через TLS. После запуска при желании можно отдельно усилить сетевую схему.
9. Бэкапы: включить.
10. Имя базы можно оставить `default_db` — она создаётся автоматически.
11. Задайте сложный пароль пользователя БД и СОХРАНИТЕ ЕГО У СЕБЯ. В чат пароль не присылайте.
12. Нажмите «Заказать» / «Создать» и дождитесь статуса «Работает».

ПОСЛЕ СОЗДАНИЯ БАЗЫ
-------------------
Откройте созданный PostgreSQL-кластер и найдите данные подключения:
- Host
- Port
- Database (обычно default_db)
- User
- Password

Не присылайте пароль. Можно прислать скрин панели, предварительно закрыв/замазав пароль.

Следующим шагом будет App Platform + Dockerfile из этого проекта.
